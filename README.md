# PRODY_CS_01 - Caesar Cipher Encryption & Decryption

This is Task 1 of the Prodigy Cybersecurity Internship.

## 🔐 Task Overview

The goal of this task was to implement a basic Caesar Cipher in Python — a type of substitution cipher where each letter in the plaintext is shifted a certain number of places down or up the alphabet.

The program allows users to:
- Encrypt a message using a shift value.
- Decrypt an encrypted message using the same shift value.

## 📜 How It Works

- The user chooses to either encrypt or decrypt a message.
- The user inputs the message and a shift value (e.g., 3).
- The program then processes the message, shifting each alphabetical character accordingly.
- Non-alphabetical characters (spaces, punctuation) are preserved as-is.
